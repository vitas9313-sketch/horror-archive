# 新增電影的範例指令（貼給有專案存取權的 Codex）

請先閱讀 `AGENTS.md`、`NOTES.md`、`CHANGELOG.md` 和 `movies.js`，並遵守現有網站的版型規則。

我想新增《厲陰宅》（The Conjuring，2013）到恐怖電影檔案館。

1. 先查證片名、導演、片長、劇情、來源與 Rotten Tomatoes 數值；不確定的項目請列為待查證，不能編造。
2. 先提供一份無重大劇透的內容草稿供我確認，請勿直接修改。
3. 我確認後，只在 `movies.js` 新增一筆電影資料，並加入一張**原創、非官方**的場景意象圖片至 `assets/`；不要使用官方海報、劇照、演員肖像，也不要仿製受保護的構圖。
4. **保持原本的高級暗黑電影誌風格**：新增一部電影時優先沿用現有元件與版型，無須重做 `index.html`、`movie.html` 或 `style.css`；但未來作者要求時可另行調整排版。
5. 檢查新增電影是否自動出現在首頁方格、詳細頁是否可點擊、分類與來源連結是否有效，並確保三部原電影不受影響。
6. 更新 `NOTES.md` 與 `CHANGELOG.md`，列出修改檔案、驗證情況、`git diff` 摘要。未獲授權不要推送至 GitHub。
